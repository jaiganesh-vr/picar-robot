AUTOPILOT-RC KNOWLEDGE BASE (snapshot 2026-10-27, repo ~/Github/autopilot-rc, branch main, 1 commit 783828f "Initial Commit", owner Jaiganesh)

== PURPOSE ==
Self-driving miniature RC car. Pi on the car senses; the computer decides; the Arduino presses RC remote buttons. Python 3.9+, OpenCV contrib, numpy, pyserial, pygame. Hardware-free simulator included.
GitHub description: "An RC car that drives itself. A Raspberry Pi streams camera and ultrasonic data, a neural network on the computer steers, Haar cascades spot stop signs and traffic lights, and an Arduino presses the remote's buttons. Comes with a simulator for testing without hardware."

== ARCHITECTURE ==
Pi (pi/) --Wi-Fi TCP--> Computer (autopilot_rc/) --USB serial 115200--> Arduino (arduino/rc_keyboard_control/) --pins--> RC remote --radio--> car.
The Pi is the client and connects to the computer (the server). Start the computer side first.
- Video: TCP 8000. Frames are [uint32 LE length][JPEG], 320x240 @10fps. Length 0 = end of stream.
- Sensor: TCP 8002. One ASCII float (cm) per line, every 0.1 s. HC-SR04 trigger GPIO23, echo GPIO24 (BCM), voltage divider on echo (5V->3.3V), gpiozero max_distance 2 m.
- Serial: 1 byte. 0 STOP, 1 FWD, 2 REV, 3 RIGHT, 4 LEFT, 6 FWD_RIGHT, 7 FWD_LEFT, 8 REV_RIGHT, 9 REV_LEFT (5 unused). Any other byte -> board replies "Invalid Command\n" and stops.
- Arduino: pins 6 right, 7 left, 10 forward, 9 reverse, active LOW. Each loop reads <=1 byte, resets the pins, holds the command 50 ms (caps it at ~20 cmd/s; faster sending queues bytes and adds lag). The last command holds; no byte for 500 ms -> STOP. All computer scripts resend the command every frame/tick to satisfy that timeout.

== DRIVER DECISION ORDER (autopilot_rc/driver.py Driver.decide) ==
Detection + MLP run on every frame first, then:
1. Ultrasonic <30 cm -> STOP (readings older than 1.0 s ignored).
2. now < stop_until (stop-sign wait) -> STOP.
3. Stop sign 0<d<25 cm and cooldown over -> STOP for 5 s, then ignore stop signs for 5 s more.
4. Red light 0<d<30 cm -> STOP.
5. MLP label: forward->FWD, left->FWD_LEFT, right->FWD_RIGHT, reverse/other->STOP.
Messages are printed only when they change (say()). Press Q in the window to quit; RCSerial.close() sends STOP.

== COMPONENTS ==
- MLP (model.py): cv2.ml.ANN_MLP with layers [38400,32,4], SIGMOID_SYM, BACKPROP, weight scale 0.001, momentum 0, 500 iterations / eps 1e-4. Input = lower half of the grayscale frame (rows 120-239, ROI_TOP=120) flattened to float32. Labels: 0 left, 1 right, 2 forward, 3 reverse. predict = argmax.
- Detection: Haar cascades models/cascades/stop_sign.xml and traffic_light.xml. detectMultiScale(scale 1.1, minNeighbors 5, minSize 30x30). Returns the box bottom row (y+h-5), or 0.
- Traffic light state: GaussianBlur 25x25 on the grayscale ROI inset by 10px; lit if max-min > 150. The brightest spot's row in (1/8..4/8)*(h-30) = red, in (5.5/8..1)*(h-30) = green. Positional, not colour-based. Position and state both come from the LAST detected box.
- Distance (DistanceToCamera): d = h / tan(alpha + atan((v - v0)/ay)), with h = 5.5 cm (15.5-10) for both signs and lights, alpha = CAMERA_ALPHA_DEG 8, v0 = 119.865631204, ay = 332.262498472 (from calibrate.py using a 9x6 chessboard and 20 photos in data/chess_board/).
- SensorReader: background daemon thread server; never closes its socket.
- common.py: deliberately does not import OpenCV (pygame and cv2 SDL clash on macOS). Holds RCSerial (port 'none' = print only; waits 2 s after opening for the Arduino reset), wait_for_stream, read_jpeg_frames, frame_to_sample, keys_to_command.
- keys_to_command: up+right FWD_RIGHT/right, up+left FWD_LEFT/left, down+right REV_RIGHT/None, down+left REV_LEFT/None, up FWD/forward, down REV/reverse, right RIGHT/right, left LEFT/left, none STOP/None. A label of None is not recorded.
- collect.py: pygame window; converts to grayscale with numpy using weights 0.299/0.587/0.114 to match OpenCV. Saves data/training/YYYYmmdd-HHMMSS.npz with train (uint8 Nx38400) and train_labels (float32 one-hot Nx4). Q/X quits. SAVE_FRAMES dumps JPEGs to data/frames/.
- model.load_dataset also reads the old Python 2 float64 .npz format.
- pi/stream_client.py: picamera2 (RGB888, 2 s settle) or any OpenCV source (webcam index, video, image sequence such as frame%02d.jpg). Paces to FRAMERATE, skips frames for faster files, optional loop, STREAM_SECONDS limit.

== COMMANDS ==
Setup: python3 -m venv .venv; source .venv/bin/activate; pip install -r requirements-dev.txt. Must use opencv-contrib-python (cv2.ml, cascades). Pi: sudo apt install python3-picamera2 python3-gpiozero python3-lgpio.
Real car: python -m autopilot_rc.control_test | python -m autopilot_rc.collect + (Pi) python3 -m pi.stream_client | python -m autopilot_rc.train | python -m autopilot_rc.evaluate | python -m autopilot_rc.driver + (Pi) pi.stream_client and pi.ultrasonic_client.
Sim: python -m simulator.simulate drive [--headless] | python simulator/render.py simulator/configs/<cfg>.json --out simulator/videos/<train|test> [--only name] | python -m simulator.train_videos | python -m simulator.evaluate_videos.
Tests: pytest (~2 min) | pytest -m "not video" (~35 s). The fake Arduino needs a pty, so it skips on Windows.

== CAVEATS ==
Detection runs even when the obstacle stop applies. The traffic light's position and state come from the last box. Light colour detection is positional on grayscale. The object height is hard-coded at 5.5 cm; re-calibrate if the mount changes. Arduino ~20 cmd/s cap. Keep collect's grayscale conversion in sync with the driver's. Env config must be set before Python starts.
